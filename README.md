# סוכן חיפוש עבודה אישי

סוכן שמחפש בשבילך עבודה פעמיים ביום, נותן לכל משרה ציון לפי קורות החיים שלך, ושולח לך למייל רק את מה ששווה לבדוק.

**מה מקבלים:**
- **חיפוש אוטומטי** באתרי הדרושים של עשרות חברות בישראל: הייטק, בנקים, ביטוח, פינטק, מגזר ציבורי ועוד ([הרשימה המלאה](COMPANIES.md)).
- **שני ציונים לכל משרה:** כמה היא מתאימה לך (0–10), וכמה היא צפויה לשלם ביחס לשכר שאתה רוצה (הערכה, 5 = השכר הרצוי).
- **מייל אחרי כל ריצה**, וסיכום שבועי ביום ראשון.
- **קורות חיים מותאמים למשרה** ב-PDF, ומכתב מקדים, כשמבקשים. בלי להמציא שום דבר.
- **ריאיון היכרות** בהתחלה, שבונה לך קורות חיים בפורמט ישראלי, גם אם אין לך.

**הכול רץ אצלך, במחשב שלך.** קורות החיים והפרטים שלך לא נשלחים לשום שרת שלנו.

## מה צריך (בדרך של Claude Code)
- **מחשב ווינדוס** שדלוק בשעות הריצה. אם הוא היה כבוי, הריצה תקרה כשהוא יידלק.
- **Claude Code ומנוי Claude** (Pro או Max). הציון רץ על המנוי שלך, בלי תשלום נוסף ובלי מפתח API.
- **חשבון Gmail** בשביל המייל. אפשר גם בלי מייל: אז הסיכום נשמר רק בדוח במחשב.
- **לא צריך:** שרת, Vercel, Supabase או מפתח API. את Node.js, אם חסר, Claude מתקין בשבילך.

**זמן:** כחצי שעה, ורובה ריאיון. **עלות:** אפס, מעבר למנוי Claude שכבר יש לך.

## מתחילים
פותחים Claude Code בתיקייה שבה רוצים את הסוכן (למשל `Documents`), ומדביקים:

```
תוריד את https://github.com/roshilabs-hq/job-search לתיקייה job-search, תיכנס אליה ותריץ את /start
```

Claude מוריד את הסוכן, ומוביל אותך שלב אחרי שלב: ריאיון, הגדרות, מייל ותזמון. בסוף מגיעה הריצה הראשונה.

## אחרי ההקמה
כותבים ל-Claude Code בתיקיית הסוכן, במילים רגילות:
- "הגשתי למשרה 12345"
- "משרה 12345 לא רלוונטית"
- "תתאים קורות חיים למשרה 12345"
- "מכתב מקדים למשרה 12345"
- "תוסיף את חברה X"
- "תשנה את האזור"
- "תכבה הכול"

מספר המשרה מופיע בכל כרטיס במייל ובדוח.

## שאלות
- **מאיפה המשרות?** מאתרי הדרושים של החברות עצמן, דרך הכתובות הציבוריות שהן מפרסמות. לא מתחברים לשום אתר בשם שלך, ולא עוקפים חסימות. דרושים לא נכלל, כי התקנון שלו אוסר איסוף אוטומטי. AllJobs אפשר להוסיף על אחריותך.
- **חסרה חברה?** "תוסיף את חברה X". אם היא על מערכת גיוס מוכרת, היא נכנסת מיד. אם לא, נשלחת בקשה, והחברה מתווספת לכולם בעדכון.
- **עדכונים?** נכנסים לבד בריצה היומית, ורק גרסה חתומה שלנו. הקבצים האישיים שלך לא נוגעים בעדכון.
- **איך מפסיקים?** "תכבה הכול". את התיקייה אפשר למחוק.
