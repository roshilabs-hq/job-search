# סוכן חיפוש העבודה באפליקציית Claude

גרסה בלי חיפוש אוטומטי, לכל מי שיש לו חשבון ב-claude.ai, גם מהטלפון אחרי ההתקנה. היא עושה ארבעה דברים:
1. **בונה קורות חיים ישראליים** בריאיון קצר, או משפרת קורות חיים קיימים.
2. **מתאימה את קורות החיים למשרה** שמדביקים.
3. **כותבת מכתב מקדים** קצר.
4. **נותנת ציון למשרה:** התאמה (0–10), ושכר צפוי ביחס לשכר הרצוי שלך (הערכה, 5 = השכר הרצוי).

## מתקינים (פעם אחת, מהמחשב, כ-3 דקות)
1. מורידים את הקובץ [job-search-il.zip](https://github.com/roshilabs-hq/job-search/releases/latest/download/job-search-il.zip). לא פותחים אותו.
2. ב-claude.ai: **Settings ← Capabilities**, ומוודאים ש-"Code execution and file creation" (או "Create and edit files") דולק. סקילים עובדים רק כשזה דולק.
3. **Customize ← Skills**, לוחצים **+**, אחר כך **Create skill**, ובוחרים **Upload a skill**. מעלים את הקובץ.
4. מוודאים שהסקיל "job-search-il" מופיע ודולק.

**איך יודעים שהצליח:** בצ'אט חדש כותבים "תבנה לי קורות חיים". Claude מתחיל לשאול שאלה אחת בכל פעם.

## משתמשים
כותבים בצ'אט, במילים רגילות:
- "תבנה לי קורות חיים" או "תשפר את הקורות חיים שלי" (ומצרפים קובץ).
- "תתאים את הקורות חיים למשרה הזו", ומדביקים את המודעה.
- "מכתב מקדים למשרה הזו".
- "תן ציון למשרה הזו".

## נתקעתי
- **לא מוצאים "Skills" בהגדרות:** בודקים ש-"Code execution" דולק (שלב 2). אם זה עדיין חסר, ייתכן שהתוכנית שלכם עוד לא תומכת בזה. [ההסבר של Anthropic](https://support.claude.com/en/articles/12512180-use-skills-in-claude).
- **"The skill could not be uploaded":** העליתם קובץ שנפתח. מעלים את ה-zip כמו שהוא הורד.
- **עדיין לא עובד?** [וואטסאפ](https://wa.me/972553048489).
